

1) Install it:
```
go install github.com/ossf/scorecard/v5/cmd/scorecard@latest
```

2) Set a GitHub token (needed to avoid rate limits — Scorecard makes a lot of API calls):****

```bash
export GITHUB_AUTH_TOKEN=your_personal_access_token
```

Generate one at github.com/settings/tokens — a read-only classic token with `public_repo` scope is enough for public repos.

3) Run it against a repo:
```
scorecard --repo=github.com/expressjs/express
```

4) Run it on your own repo (useful for your Inception/kuri work):
```
scorecard --repo=github.com/ahmadal-quraan/Inception
```

**Useful flags:**

- `--format=json` — structured output if you want to parse it or feed it into CI
- `--show-details` — more verbose explanation per check
- `--checks=Branch-Protection,Signed-Releases` — run only specific checks

**5. Or skip installing it entirely** — go to scorecard.dev, search the repo name, and see if it's already been scored (many popular OSS repos are scanned continuously).

**Bonus: automate it** — add the [Scorecard GitHub Action](https://github.com/ossf/scorecard-action) to a repo you maintain so it re-scores on every push and publishes results to the OpenSSF badge you can drop in your README.
