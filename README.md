## Holy Questions 
>  For anything new you wanna learn in depth, ask yourself these question.
1. What is it?
2. Why does it exist?
3. How do I use it?
4. What breaks it?
5. How does it work internally?
6. How is it built?
7. Can I build a small version of it?
